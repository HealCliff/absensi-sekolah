# Panduan Pengguna

## Guru

1. Login menggunakan NIK dan password.
2. Buka menu **Absensi**.
3. Pilih **Absen Masuk** dan konfirmasi.
4. Jika melewati batas jam masuk, isi alasan keterlambatan.
5. Pilih **Absen Pulang** setelah selesai bekerja.
6. Jika pulang sebelum batas, isi alasan.
7. Jika pulang setelah batas, alasan tidak diperlukan.
8. Buka menu **Riwayat Absensi** untuk melihat catatan pribadi.

## Tata Usaha

- **Dashboard**: melihat ringkasan kehadiran.
- **Data Guru**: menambah, mengubah, dan menghapus data guru.
- **Manajemen Akun**: membuat akun, mengubah status, reset password, dan menghapus akun.
- **Rekap Absen**: melihat, mengoreksi, dan input absensi manual.
- **Jam Absensi**: mengubah batas jam masuk dan jam pulang.
- **Hari Libur**: mengatur libur satu tanggal atau rentang tanggal.
- **Laporan**: melihat laporan tahunan/bulanan dan export Excel/PDF.
- **Audit Log**: melihat aktivitas perubahan data pengguna.

## Kepala Sekolah

- Melihat dashboard ringkasan.
- Melihat laporan tahunan atau bulanan.
- Melihat audit log.
- Tidak dapat mengubah data operasional.

## Aturan Absensi

- Absen masuk setelah batas jam masuk membutuhkan alasan.
- Absen pulang sebelum batas jam pulang membutuhkan alasan.
- Absen pulang tepat atau setelah batas jam pulang tidak membutuhkan alasan.
- Absensi pada hari libur dinonaktifkan dan juga ditolak oleh backend.
- Jam dan tanggal absensi mengikuti waktu server `Asia/Jakarta`.
